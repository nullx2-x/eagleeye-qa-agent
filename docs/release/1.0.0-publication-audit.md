## Security boundary

- Workflows keep repository contents read-only. CodeQL alone receives
  `security-events: write`, plus `actions: read` to inspect workflow metadata.
- Pull-request code does not receive a broadly writable token.
- Third-party Actions are pinned to full commit SHAs and checkout credentials are not persisted.
- Private repositories cannot upload CodeQL results without GitHub Code Security. During the
  private pre-release gate, SARIF is retained for 14 days as a workflow artifact. Once public,
  the same workflow uploads SARIF to GitHub Code Scanning.
- No check is disabled, ignored with `continue-on-error`, or removed from the release gate.
- EagleEye's replay and repair boundaries remain loopback-first, explicitly authorized,
  root-confined, `shell=False`, time-limited, evidence-producing, and human-approved.

## Compliance and privacy position

The default distribution is local-first and data-minimizing. It does not claim that installing
the software alone makes an operator compliant with APPI, GDPR, Chrome Web Store policy, or an
AI-provider contract. Operators remain responsible for authority to test, notices, lawful basis,
retention, access control, provider terms, cross-border transfers, incident response, and any
remote deployment controls. See [Privacy](../../PRIVACY.md), [Security](../../SECURITY.md), and
[Compliance](../../COMPLIANCE.md).

The English README provides the no-account Quick Start. The submission demo is available at
<https://youtu.be/zLSLiG7QYr4>, and the Devpost entry is available at

## Residual risk and rollback

- A Starlette test-helper deprecation warning remains non-blocking and does not affect runtime behavior.
- External advisory services and AI providers can be temporarily unavailable; deterministic tests remain authoritative.
- Remote or multi-user hosting is outside the secure default and requires the controls listed in `SECURITY.md`.

Rollback is performed by reverting the release commit and disabling the GitHub Release. If a
secret is ever discovered, revoke it first, remove it from all reachable history, and repeat the
full audit before republishing.
